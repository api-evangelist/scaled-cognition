# Scaled Cognition

> Scaled Cognition is a Mountain View, California AI model lab and enterprise platform company behind
> APT-1, the Agentic Pretrained Transformer — a frontier model pretrained on action prediction rather
> than token prediction and purpose-built for enterprise customer-experience agents. The commercial
> surface is an Agent Builder platform exposed to customers through a stateless RESTful API that can
> run in Scaled Cognition's SOC 2 Type II cloud, in a customer VPC, or fully on-premises.

Generated by API Evangelist (https://apievangelist.com) on 2026-08-26 from the public Scaled
Cognition surface. Scaled Cognition does not publish an llms.txt of its own; https://www.scaledcognition.com/llms.txt
returned 404 on 2026-08-26. This file is API Evangelist's third-party summary, not the company's.

## Important: there is no public API contract

Scaled Cognition markets an API but publishes no developer portal, no API reference, and no
machine-readable contract. As of 2026-08-26:

- https://studio.scaledcognition.com/api/openapi.json -> 401 {"error":"Not authenticated."}
- https://studio.scaledcognition.com/api/v1/openapi.json -> 401 {"error":"Not authenticated."}
- https://studio.scaledcognition.com/docs -> 307 redirect to /login?next=%2Fdocs
- https://api.scaledcognition.com/ -> 403 from an AWS ELB (every path)
- https://docs.scaledcognition.com -> hostname does not resolve
- No GraphQL, AsyncAPI, gRPC/protobuf, WSDL, MCP server or A2A agent card was found on any host.

An OpenAPI document demonstrably exists behind the Agent Builder login. An agent cannot read it, and
neither can a prospective integrator. To evaluate this API you must go through
https://www.scaledcognition.com/contact ("Schedule a Demo").

## Product

- [Explore Platform](https://www.scaledcognition.com/product/explore-platform): Agent Builder (browser
  authoring with built-in validation), APT SDK (Python), AgentTwin (turns historical call transcripts
  into production-ready agents), GenAPI simulation, Test Case Generator, Generative Virtual Customers,
  Agent Scorecards, Agent Monitor, Agent Defender. Workflow is Spec -> Sim -> Ship -> Scale.
- [Meet APT-1](https://www.scaledcognition.com/product/meet-apt-1): the Agentic Pretrained Transformer.
- [Go Live](https://www.scaledcognition.com/product/go-live): deployment.
- [Voice](https://www.scaledcognition.com/product/voice): real-time voice agents; integrates with
  LiveKit and telephony (Twilio, Telnyx, direct SIP).
- [AI Info](https://www.scaledcognition.com/ai-info): the company's own machine-oriented fact page.

## Agent access policy

https://www.scaledcognition.com/robots.txt explicitly allows GPTBot, ChatGPT-User, OAI-SearchBot,
anthropic-ai, ClaudeBot, GoogleOther, Google-Extended, Googlebot, Applebot, Bingbot and PerplexityBot;
it disallows only Brightbot. The marketing site is open to agents. The product API is not.
